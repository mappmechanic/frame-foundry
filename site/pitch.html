01 / Thesis · FrameFoundry

Keep shipping good-quality edits.
Not more editing hours.

FrameFoundry: keep shipping good-quality edits from deterministic code plus a few cheap LLM decisions, at minimal cost.

Raw footage + one-line goal → a recorded, verified clip.

A code-first video factory, orchestrated by 8090 Software Factory. This is a static presentation of recorded evidence—not a live generation service.

02 / Problem

The footage is ready.
The edit is still a project.

Family trips and creator shoots leave hours of raw footage. Finding the story, cutting it, adding context, and checking the result is slow, repetitive work.

Find the moments

Separate useful shots and speech from everything else.

Build the story

Turn a goal into an intentional sequence—not a random montage.

Check every output

Keep audio, cuts, format, and on-screen text trustworthy.

The opportunity: make repeatable editing a build process, with humans setting the goal.

03 / Pipeline

Deterministic where possible.
Generative where useful.

Refinery + validation

Code inspects media, compiles the timeline, renders overlays, and checks audio, duration, frames, and output format.

Planner + Judge

One generative Planner call proposes the story; one ordinary Judge call evaluates semantic quality. Missing calls or measurements stay unavailable.

Bounded Decisions

Proposed / experimental: choose from bounded candidates. Not claimed as the promoted default; matched evaluation is pending.

Inspect → plan → compile → render → validate → judge → publish recorded evidence

These are pipeline roles, not a claim that every run has full inference coverage. This page performs no rendering or model calls.
